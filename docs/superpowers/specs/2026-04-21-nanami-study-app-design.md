## コンセプト：「共通テスト英語の裏技集」

> **父親から娘への、超効率的な攻略本。ズルをする。近道をする。ゲームを攻略する。**

七海への設計原則：
- 英語が嫌いでOK。**試験の攻略方法**を学ぶアプリ
- 最初は答えとヒントを惜しみなく出す。**「わかった気」を意図的に作る**
- マスターコースで「あれ、出来ない」を体験させる。**その落差が本物の動機になる**
- 「今日はここまで」ではなく**「いけるところまで行く」**
- 表示するのは**「できるようになったこと」だけ**。出来なかったは数えない

---

## 学習心理の流れ（設計意図）

```
STEP1：攻略法を見る（答え先出し）
  → 「なんかわかった気がする」

STEP2：答えを知った状態で問題を読む
  → 「あ、なるほどそういうことか」

マスターコース：本番レベルを答えなしで解く
  → 「あれ、出来ない…」
  → 「分かった気になってた」

  ↓ この落差が本物の動機になる

  → 「本当にわかりたい」
  → 「出来るまでやってみる」
```

## コアループ（時間制限なし）

```
アプリを開く（「今日の問題」ではない）
  ↓
攻略マップ画面：「どのボスに挑む？」
（攻略済み✅ / 挑戦中🔥 / 未着手　の表示）
  ↓
ボスを選ぶ（または「おまかせ」で自動選択）
  ↓
STEP 1：裏技を読む
  ↓
STEP 2：答え付き問題を読む
  ↓
[ぜんぶわかった] → マスターコースへ
[まだわからない部分がある] → 原因を選ぶ（A〜E）
  ↓
原因別サポート → [納得した] → STEP 2に戻るか マスターコースへ
  ↓
マスターコース（本番レベル・ヒントなし）
[正解] → 🎉「攻略！」バッジ獲得 → 次のボスへ
[不正解] → どこで崩れた？原因特定 → 同じ問題を再挑戦
  ↓
やめたいときはいつでも終了（途中終了OK・進捗は保存される）
```

## 難易度バランス（出題アルゴリズム）

**詰まったことがある問題を連続で出さない。勝ちを挟んでから戻す。**

| 割合 | 問題の性質 |
|------|-----------|
| 20% | 余裕で勝てる問題（自信回復用） |
| 70% | 少し考えればできる問題（成長域） |
| 10% | ちょっと背伸びが必要な問題（挑戦） |

**苦手問題の処理：**
- 同じ問題タイプで3回連続詰まったら → 簡単な別タイプを2問挟んでから戻す
- 「何度もわからない」ではなく「またこのボスか、今度こそ倒す」という演出

---

## 「わからない」の原因分類と対応

「わからない」を押したら **原因を1タップで選ぶ**：

| 選択肢 | Claudeのサポート |
|--------|----------------|
| A. 単語がわからない | 該当語の意味＋言い換えペアを表示 → 問題に戻る |
| B. 文の構造がわからない | 主語/動詞/目的語を分解して日本語表示 → 戻る |
| C. このテーマを知らない | テーマを30秒で日本語解説 → 戻る |
| D. 何を聞かれているかわからない | 設問を日本語で言い換え → 戻る |
| E. ぜんぶよくわからない | Claudeとの対話モードへ |

**「納得した」ボタンは常時表示。七海が押したタイミングで次へ進む。**

## 中断コマンド（詰まっても止まらない）

| コマンド | 動作 |
|---------|------|
| 🔴「むずかしすぎる」 | 同タイプ・同テーマで難易度1段下げた問題に差し替え |
| 📖「この単語がわからない」 | 単語をタップ → 意味＋言い換え例 → 問題に戻る |
| ⏭「あとで」 | 保留リストに追加 → 次の問題へ（連続挫折を防ぐ） |

## 進捗表示（ポジティブのみ）

**「出来なかったこと」は数えない。「出来るようになったこと」だけを見せる。**

```
📊 七海の攻略状況

🏆 攻略済みボス
  ✅ メール読解（第5問型）
  ✅ 言い換えドリル

🔥 挑戦中
  🔥 アウトライン作成（第8問型）

💪 習得した裏技：7個
⚡ 連続プレイ：3日
```

**表示しないもの：** 不正解数・間違えた問題リスト・「まだ攻略できていない」

## 問題タイプ（ボス）と裏技（攻略公式）

### 🏆 ボスA：アウトライン作成（第8問 / 17点）

**裏技：**
> 「資料1の"問題点"＋資料2の"解決策"→ 答えは"その論理的帰結"。感情的に正しそうな選択肢が1つ混じってる。それが罠。冷静に"論理だけ"で選べ。」

**攻略3ステップ：**
1. 資料1の「問題」と資料2の「解決」をそれぞれ1行でまとめる
2. 2つを繋げると「だから〜になる」という文が完成する
3. その文に最も近い選択肢を選ぶ

---

### 🏆 ボスB：メール読解（第5問 / 16点）

**裏技：**
> 「メールで読むのは2つだけ：①最後の一文（結論）②数字（日付・時間・金額）。その2つを照合すれば答えが出る。本文全部読もうとするな。」

---

### 🏆 ボスC：説明文・記事（第7問 / 16点）

**裏技：**
> 「筆者の主張は最初か最後の段落にある。中間は"根拠"か"反論"。段落ごとに"主張・根拠・反論"とメモるだけで構造が見える。」

---

### 🏆 ボスD：エッセイ添削（第4問 / 12点）

**裏技：**
> 「教師のコメントが"ヒント"そのもの。コメントを読んでから、それを満たす選択肢を選ぶだけ。英文を直すんじゃない。コメントと選択肢をマッチングするゲームだ。」

---

### 🏆 ボスE：物語文（第3・6問 / 各9〜12点）

**裏技：**
> 「時間を表す単語だけハイライト：yesterday / two days ago / last night / next week。それを並べ直すと時系列が完成する。」

---

### ⚔️ 基礎スキル：言い換えドリル（全問横断）

**裏技：**
> 「正解の選択肢は必ず本文の言葉を別の言葉に変えてある。"本文と同じ単語"が使われている選択肢は罠が多い。」

| 本文 | 選択肢 |
|------|--------|
| at no cost / complimentary | free |
| postpone / put off | change the date |
| significant / considerable | large / important |

---

### ⚔️ 基礎スキル：事実／意見の仕分け（全問横断）

**裏技：**
> 「数字・日付・固有名詞が入ってたらFact。"I think" "should" "best"が入ってたらOpinion。これだけで8割当たる。」

## 問題生成（Claude API）

問題はDBに事前登録しない。Claude Sonnet APIがセッションごとに生成。

**生成パラメータ：**
```json
{
  "problem_type": "outline",
  "difficulty": 2,
  "theme": "technology",
  "csat_section": 8,
  "mode": "answer_first",
  "hint_level": "high"
}
```

**モード：**
- `answer_first`：答えと解説を先に表示するSTEP2用
- `challenge`：答えなしのマスターコース用

## データベース設計

### `sessions`テーブル
- id, user_id, timestamp
- problem_type, difficulty, theme
- mode（answer_first / challenge）
- generated_question（JSON）
- result（cleared / wakaranai / pending）
- wakaranai_cause（vocabulary / structure / background / question / unknown）
- resolved（boolean）
- ai_conversation（JSON）

### `mastery`テーブル
- user_id, problem_type
- status（未着手 / 挑戦中 / 攻略済み）
- cleared_at, attempt_count

### `difficulty_state`テーブル
- user_id, problem_type
- current_difficulty（1〜5）
- consecutive_failures（連続失敗カウント）

### `words`テーブル（語彙サポート）
- id, word, meaning, pos
- paraphrase_pairs（JSON）
- category（JSON）
- collocation, difficulty
- argument_role, synthesis_type

## 開発フェーズ

1. **Phase 1**：攻略マップ ＋ ボスA（アウトライン）＋ ボスB（メール） ＋ STEP1〜3の基本フロー
2. **Phase 2**：「わからない」原因分類（A〜E）＋ AI対話
3. **Phase 3**：難易度バランスアルゴリズム ＋ 進捗ポジティブ表示
4. **Phase 4**：全ボス追加（C〜E）＋ 基礎スキル（言い換え・事実/意見）
5. **Phase 5**：リスニング ＋ 音声対応
