## 1. プロジェクト基本方針

### アプリの目的と哲学

- **名前：** 共通テスト英語 完全対策
- **対象ユーザー：** 七海（ADHD傾向・大学受験生）← 現在はテスト段階
- **コアコンセプト：** 「答えファースト学習法」— 先に答えと解説を見てから一人で解く
- **アプリの性格：** 「攻略」アプリ。ゲームのボスを倒す体験設計。説明は少なくするが、根拠は必要な時に見られる設計
- **デザイン方針：** 個人アプリ感は排除。教育プロダクト・プロトタイプとして見せる

### 答えファーストの根拠

「先に答えを見ること」= ズルではなく、正しい学習手順。
解き方を知らない状態で悩んでも時間がかかるだけで身につかない。
コツ（解き方のパターン）を知ってから問題を見ることで「なるほど」体験が生まれる。

## 2. 共通テスト戦略に関する調査結果（2026-04-22 リサーチ済み）

### 2025年度 正答率データ（英才予備校調べ）

| 問 | 正答率 | 備考 |
|---|---|---|
| 第1問 | 高め | 短い実用文 |
| 第2問 | **67.5%** | 最高。ブログ・アンケート |
| 第3問 | 高め | 短編物語 |
| 第4問 | 中 | エッセイ添削 |
| 第5問 | 52.5% | 複数文書 |
| 第6問 | **41.8%** | **ワースト1位** |
| 第7問 | やや難 | 説明文＋スライド |
| 第8問 | **47.1%** | 配点最大だが第6問より易しい |

### 大手予備校の推奨解答順（東進・駿台・Z会）

**推奨順：第2→第3→第1→第4→第5→第7→第8→第6**

- 第6問は「時間泥棒」（長い物語文、点数に対して時間がかかりすぎる）
- 第6問を最後に回して時間が足りなくなっても損害が少ない
- 「第8問から解く」を推奨している大手予備校はなし（調査済み）

### アプリの方針（この調査を受けた決定）

**「第8問から始める」の意味を再定義する：**
- テスト本番の解答順 ≠ 学習の優先順位
- 学習の優先順位として第8問を最初に攻略する理由：
  - 配点17点（全体の17%）で点数効率が最大
  - 解き方のパターンが最も明確で攻略しやすい
  - ここを取れると「英語は攻略できる」という自信につながる
- アプリの「マップ」はデフォルト「配点が高い順」ソートで第8問が最上位に表示される

**未決事項：** `/about` ページで「なぜ第8問から？」を説明する際、上記の正答率データと解答順の根拠をどう伝えるか → Claude Design と相談後に文章を確定する

## 3. ユーザーフィードバック（七海）

- 「使いづらい」「感覚的に伝わらない」
- LINEで別途説明しないとフローが理解できなかった
- **根本原因：** 「なぜこのやり方なのか」が先に見えないとADHDは次に進めない
- **対策方針：** 「なぜ？」を先に解消する設計。オンボーディング改善 or `/about` ページ

## 5. 実装済み機能（フェーズ1 + 追加）

### フェーズ1（移管前）

- 8問タイプ × 5難易度 = 40問をSupabase DBに格納
- 答えファースト練習（STEP 1〜3フロー）
- 難易度セレクター（デフォルト：レベル1）
- 「先に答えを見て考える」（問ごと個別ピーク）
- JP/EN翻訳トグル（本文・設問・選択肢それぞれ）
- ヒントボタン（本文の該当箇所を黄色ハイライト）
- タイマー（目標時間超過で赤）
- 「どこがわからない？」サポート（原因選択→AI解説）
- ProgressBanner・マップソート（配点順/易しい順/短時間順）
- Supabase Auth（メール認証）
- Vercel 自動デプロイ（GitHub: naohoro/nanami-english-study）

### 6-2. オンボーディング改善

**課題：** 現在の3枚スライドでは「なぜこのやり方なのか」が伝わらない（七海フィードバック）

**方針：**
- 「なぜ？」を先に解消してからCTAを見せる
- 理由とCTAを一体化する設計
- `/about`ページへの導線を最初から持たせる案あり

**現在のオンボーディング3スライド：**
1. 📚 「共通テスト英語を最短で攻略するアプリ」
2. 🎯 「点数が大きい問題からやるのが正解」
3. ✨ 「使い方はシンプル」（3ステップ）

**問題点：** スライド2が「なぜ第8問から？」の説明になっているが、根拠データがない。ADHD傾向のユーザーは納得できないと次に進めない。

## 8. 技術構成メモ

- **フレームワーク：** Next.js 15（App Router）
- **DB/Auth：** Supabase（PostgreSQL + Row Level Security）
- **デプロイ：** Vercel（GitHub: naohoro/nanami-english-study / main ブランチ自動デプロイ）
- **AI：** Anthropic Claude API（ヒント・翻訳・サポートメッセージ生成に使用）
- **重要：** step2の問題表示はDBから取得（APIトークン消費なし）。AI呼び出しはユーザー操作時のみ
